# ExpressJS Template for CS3425 Course Project
This version of the course project will be developed and run on your local machine instead of Guardian/Colossus. Without the classdb web server to process HTTP requests, you need to handle them yourself. ExpressJS is a minimalist web framework that makes setting up the server and routes simple. This template contains dependencies and basic structure to get you started.

## Required Software:
* [NodeJS](https://nodejs.org/en/download) - Install the latest LTS version via Node Version Manager (nvm) or prebuilt installer. Follow this [installation guide](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/Express_Nodejs/development_environment#installing_node) from MDN.
* [Git](https://git-scm.com/install/) *(Optional)* - Version control software helpful for collaborating with your group members.
* [Visual Studio Code](https://code.visualstudio.com/download) *(Optional)* - Free and powerful Integrated Development Environment that integrates nicely with git.

## Getting Started

Clone the repository, install dependencies, create a local .env file with your database credentials, and start the server:

```bash
git clone https://github.com/mtchkelly/cs3425-express.git
cd cs3425-express
npm install
cp .env.example .env
npm run dev
```

Open <http://localhost:3000/> in a browser.

The `.env` file contains your database credentials a session secret. It is ignored by git and should never be committed.

## Using This Project Template

The Express server and database connection are setup for you. Example HTML templates and route/controller handlers are provided for your reference as you start developing.

### File Structure

`app.js`: Starting point for the web server.

`router.js`: Routes are Express code that associate an HTTP verb (GET, POST, DELETE, etc), a URL path/pattern, and a function that handles that pattern.

`controller.js`: Contains the callback functions with the application logic used by the router.

> ***Read [MDN Web Doc's](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/Express_Nodejs/routes) primer on routes and controllers for more details.***

`db.js`: The connection pool used to send queries to your database.

`.env`: Contains secrets like your database username and password so they are not hardcoded or tracked in version control. These values are accessible through `process.env.[VARIABLE_NAME]`.

`package.json`: npm dependencies are specified here.

`package-lock.json`: Automatically managed and generated by npm from `package.json`.

`views/`: Template files for ejs that generate static HTML for the client.

  `views/partials/`: Smaller sections of a full ejs file that get shared across several templates.

`public/`: Static files accessible directly by the client including front-end javascript, css, and images.

### Running Database Queries

Execute your SQL statements using the connection pool provided in `db.js`. Statements are automatically prepared with `?`s in the statement argument. Values are subtituted in the provided order from the array argument. 

```js
import db from './db.js';

router.get('/users/:id', async (req, res, next) => {
  try {
    const [rows] = await db.execute(
      'SELECT * FROM users WHERE id = ?',
      [req.params.id]
    );

    res.json(rows);
  } catch (error) {
    next(error);
  }
});
```

### Embedded Javascript (ejs) Basics

Similar to php, ejs allows you to conditionally render HTML and respond with dynamic data. Use `<%` for control flow and `<%=` to print escaped values. To send a page back to the client, use `res.render(view: string, options: object)`. The template will have access to any data passed through the `options` argument. The project template is configured so ejs views automatically recieve a copy of `req.session.user` on every request. `user` will be null if there is no logged in session.

```html
<% if (user) { %>
  <h2>Welcome <%= user.name %></h2>
<% } %>

<ul>
  <% items.forEach(item => { %>
    <li><%= item %></li>
  <% }); %>
</ul>
```

### Session Management

Session data is available on `req.session`. For example, to set a user id after logging in:

```js
req.session.user = { id };
const { userId } = req.session.user;
```

To end a session, such as when a user logs out:

```js
req.session.destroy((err) => {
  if (err) return next(err);
  res.clearCookie('connect.sid');
});
```

### Password Hashing

You can use the npm package [bcrypt](https://www.npmjs.com/package/bcrypt) to hash passwords in your application code instead of relying on database functions like `sha2()`. Follow the examples in package description.

## Next Steps & Tips

Keep your code well documented and organized. This may involve splitting your controller and router into separate modules, or making services that handle frequently used database operations.

The server will automatically restart when it detects changes in its source code. You must refresh your browser to see new changes in the ejs template files.
